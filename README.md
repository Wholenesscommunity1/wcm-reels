# WCM Reels

Public hosting for Wholeness Community Marketplace Instagram reels (@wholenesscommunity), plus the scripts that build them.

- `reels/` finished 1080x1920 MP4s and JPG cover frames. Public URL pattern:
  `https://raw.githubusercontent.com/Wholenesscommunity1/wcm-reels/main/reels/<file>`
- `wcm_30_day_content_calendar.csv` the content plan (hooks, lines, captions, hashtags)
- `make_reels.py` renderer: characters, scene types, ffmpeg encode (needs Pillow + ffmpeg, Poppins font)
- `render_calendar.py` turns a calendar row into a reel: `python3 render_calendar.py 12` renders day 12
- `music.py` builds an original backing track for each reel (synthesized in code, no samples or licensed music). `make_reels.py` calls it on every render, so no reel goes out silent. Moods: upbeat (recipes), drive (workouts), bright (humor), warm (habits), calm (rest, encouragement, spirituality); `mood_for_row(theme, dimension)` picks one
- `voice.py` narrates recipe reels with Piper (offline text to speech). The voice model (about 60 MB) is fetched once from the Piper GitHub release into `~/.cache/wcm_voices`; `pip install --break-system-packages piper-tts` first. Hugging Face is blocked from the render box, GitHub is not
- `make_cards.py` draws 1080x1350 still cards for feed posts in the same style (`cards/`); each card illustrates the first line of its caption so the picture matches the tag line
- `calendar.py` generates the CSV from the content list inside it
- Render options: `WCM_TAG=v2 python3 render_calendar.py 12` adds `_v2` to the file name (use a new tag whenever a reel that is already queued in Metricool is re-rendered, so Metricool fetches the new file instead of reusing the old one); `WCM_OUT=/some/dir` renders somewhere other than `reels/`
- `schedule_plan.json` what was scheduled in Metricool and when
- `recipes/YYYY-MM-DD/` the daily recipe reels (separate task from the weekly lifestyle reels): `src/hero.jpg`, `src/cook.jpg`, `src/enjoy.jpg` are photorealistic AI stills (Canva generate-image, Gamma as fallback), `<date>_<dish>.mp4` and `_cover.jpg` are the finished reel and cover, `caption.txt` the full-recipe caption. Public URL pattern: `https://raw.githubusercontent.com/Wholenesscommunity1/wcm-reels/main/recipes/<date>/<file>`
- `recipes/recipes_<range>.json` the recipes themselves (title, servings, times, ingredients, steps, short spoken steps, image prompts, hashtags)
- `make_recipe_reels.py` renders a recipe reel from the three stills: hook over the finished dish, key ingredients with amounts, one narrated subtitle card per step, CTA outro; Ken Burns cuts every 2 to 3 s, music from `music.py`, voice from `voice.py`, 1080x1920, crf 29 (about 7 MB each). `python3 make_recipe_reels.py recipes/recipes_2026-11-11_to_11-24.json 2026-11-13`
- `recipe_captions.py` writes each `caption.txt` (under 2,200 characters, every ingredient and amount kept) and appends the recipes to the calendar CSV as Theme = Recipe rows with extra Ingredients / Steps / Title / Servings / Prep / Cook / Cuisine / Meal columns
- `stitch_tiles.py` rebuilds a full 1080x1920 still from Canva page thumbnails: the render box cannot download Canva or Gamma files directly (the egress proxy refuses those hosts), so a generated image is placed across eight 540x480 tile pages of a scratch Canva design (DAHaf8VhbOQ, pages 12 to 19), read back as 600x533 thumbnails and stitched, with the tile order recovered from seam continuity

## Weekly workflow (automated)
1. Pull Metricool Instagram analytics for the last 14 days; note which reels got the most reach, plays, saves and shares.
2. Write 7 new calendar rows leaning toward the best-performing themes and dimensions; keep all nine dimensions in rotation over the month.
3. Render with `render_calendar.py` (reads the CSV in the repo root, writes to `reels/`, music included), commit and push to `main`. Check the result has sound: `ffmpeg -i reels/<file>.mp4 -af volumedetect -f null -` should report a mean volume near -16 dB, not -91 dB.
4. Schedule each in Metricool as an Instagram REEL plus a Facebook REEL in the same post (providers instagram and facebook, `facebookData` type REEL with the hook as the title) at the best hour from `getBestTimeToPostByNetwork` (weekdays ~10:00 ET, recipes ~18:00 ET Tue/Thu, Sun ~12:00 ET). The brand's Facebook Page is connected in Metricool (page id in `getBrandSettings`).
5. Send a short summary to Sandip.
